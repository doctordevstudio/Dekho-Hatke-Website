DEKHO HATKE - pure static site (HTML/CSS/JS). No Python, no server, no build.

DEPLOY: upload this whole folder to Cloudflare Pages.

EDIT SETTINGS: assets/config.js (Render URL, AdSense, Analytics tokens).
EDIT EMAIL: search "your@gmail.com" in contact/index.html and replace.
EDIT SOCIAL LINKS: follow/<name>/index.html (the Follow button href).
NEW ARTICLE:
 1. Copy a folder in blog/ (e.g. blog/cpp-pointers-explained) and rename it.
 2. Edit the title, description, text and canonical URL inside its index.html.
 3. Add a card for it in index.html (copy an existing <article class="card post">).
 4. Add an entry in assets/posts.js (powers search, bookmarks).
 5. Add its URL in sitemap.xml and llms.txt.
